# ADR-0097 — 필드별 소유: 마스터 소유 값은 복사하지 않고 지금 마스터를 따른다 · 상품 소유 값은 탑재 때 복사한다

> 상태: 채택 (2026-10-31 사용자 결정) · 날짜: 2026-10-31 · **미구현** — 구현은 아직 「값 전부 스냅샷」(ADR-0002 원래 규칙)이다.
>
> **개정** [[기능/상품/결정/ADR-0002-탑재-값스냅샷]] — 「탑재 = 마스터 값 전부 복사」를 「상품 소유 값만 복사」로 좁힌다. 구조만 공유한다던 자리에 마스터 소유 값이 더해진다.
> 선례: 담보분류는 이미 스냅샷 대상이 아닌 뼈대 칸이다([[기능/상품/결정/ADR-0090-특약그룹-담보분류기본그룹-상품사용자그룹]]).

## 맥락

ADR-0002 는 탑재 순간 마스터 값을 전부 상품담보로 복사하고, 이후 마스터 값 변경은 이미 탑재된 상품담보에 흘러들지 않게 했다.
현행 시스템 지급금액표 기획(2026-10-31 대조)에서 담보 쪽에 새 값이 생긴다 — 통합치료비의 급부 정액표, 체증, 주요치료비 단서문구 같은 「유형 특성」이다.
이 값들은 담보를 설명하는 사실이라 상품마다 다르게 둘 까닭이 없고, 담보에서 고치면 탑재한 상품에 바로 반영돼야 한다(사용자 동기 2026-10-31 — 「담보에서 바꾼 급부명 · 유형 특성은 상품에 바로 반영돼야」).
값 전부를 복사하면 담보에서 정액표를 고칠 때마다 상품마다 「현재 마스터 값 가져오기」를 눌러야 한다.

## 결정

1. **값마다 주인이 하나다 — 마스터 소유 / 상품 소유.**
   - **마스터 소유** — 탑재 때 복사하지 않는다. 상품에서는 읽기 전용이고, 늘 지금 마스터 값이다.
   - **상품 소유** — 지금처럼 탑재 때 복사하고 상품에서 고친다. 마스터가 바뀌면 상품담보 값 화면의 「현재 마스터 값 가져오기」로 받는다([[기능/상품/상품]] §3.4).
2. **분류.**

   | 소유 | 값 |
   |---|---|
   | 마스터 | 급부명 · 구조 · 담보분류(이미 그렇다) · **유형 특성** — 급부 정액표 · 급부 체증 · 담보 단서문구 |
   | 상품 | **지급률** · 감액 · 면책 · 운영 가입금액 · 담보속성 |

   지급률은 상품 소유다 — 탑재 때 복사하고 상품에서 고친다. 아무도 정하지 않으면 100% 다.
   (버린 안 B — 「상품이 안 정했으면 지금 마스터를 따라간다」 — 는 한 값이 상품 · 마스터 둘 중 어디서 오는지 그때그때 갈려 아래 3과 어긋난다.)
   가입금액은 담보 레벨 값 하나(금액 여러 개)다 — 마스터 값은 가능한 가입금액 전체이고, 탑재 때 상품담보로 복사돼(상품 소유) 상품이 운영하지 않는 금액을 지운다 = 운영 가입금액([[기능/담보/담보]] §3.3).
3. **덮어쓰기 층이 아니다.** 한 값의 주인은 하나다 — 상품이 마스터 소유 값을 덮어쓰는 길도, 마스터 소유 값이 상품 값의 기본으로 흘러드는 길도 없다. ADR-0002 가 버린 「구체적 오버라이드 > 마스터 값 > 기본값」 해소 순서를 되살리지 않는다.
4. **소유는 필드 정의의 속성이다.** 어느 필드가 마스터 소유인지는 필드 정의(코드 마스터 폼 › 필드, [[기능/마스터/마스터]] §3.1)가 가진다 — 값 행마다 적지 않는다. 표식의 이름 · 모양은 구현 때 확정한다.

## 이유

- 담보를 설명하는 사실(이름 · 유형 특성)은 담보 하나에 한 벌이어야 고칠 곳이 하나다. 복사하면 상품 수만큼 옛 값이 남는다.
- 상품마다 실제로 다른 값(지급률 · 감액 · 면책 · 운영 가입금액)은 ADR-0002 그대로 상품의 복사본이 지킨다 — 「마스터를 고쳤다고 판매 설계된 상품의 값이 바뀌면 사고」라는 ADR-0002 의 이유는 이 값들에 대해 그대로다.
- 값마다 주인이 하나라 해소 계산이 없다 — 마스터 소유는 마스터에서, 상품 소유는 상품담보에서 읽는다. 라이브 오버라이드의 복잡함(어디서 왔는지 매번 계산)이 생기지 않는다.

## 버린 대안

- **값 전부 스냅샷 유지(ADR-0002 그대로)** — 유형 특성을 고칠 때마다 상품마다 가져오기를 눌러야 하고, 안 누른 상품은 조용히 옛 정액표로 찍힌다.
- **덮어쓰기 층(상품 > 마스터 > 기본값)** — ADR-0002 가 버린 라이브 오버라이드다. 한 값이 어디서 왔는지 읽을 때마다 거슬러 올라간다.
- **지급률 = 「상품이 안 정했으면 지금 마스터를 따라감」(B)** — 상품 값이 비었는지에 따라 주인이 바뀐다. 사용자는 A(탑재 때 복사 · 상품에서 고침 · 아무도 안 정하면 100%)를 골랐다.

## 결과와 감수하는 비용

- **확정한 상품의 약관도 바뀐다** — 마스터 소유 값(급부명 · 정액표 …)을 고치면 이미 확정한 상품의 책자도 다시 조립하면 달라진다. 확정본 보호는 개정 이력 기획([[공통/기술/결정/ADR-0026-이력개정-이력일자-작업본확정]], MVP 이후) 때 정한다 — 미결.
- 상품담보 값 화면은 마스터 소유 칸을 읽기 전용으로 보인다(가져오기 · 비우기 아이콘 없음).
- 이미 스냅샷된 마스터 소유 값 행(있으면)은 구현 때 지운다 — 지금 마스터 소유로 분류된 값 가운데 폼 값은 아직 없다(정액표 · 체증 · 단서문구 특성은 기획 단계, 급부명 · 구조 · 담보분류는 원래 뼈대).
